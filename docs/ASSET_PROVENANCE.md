# Asset provenance

Heatline MX ships **no third-party or imported art, audio or fonts**. Everything is generated by
this project's code or comes with the engine.

| Asset | Source |
|---|---|
| Bikes and riders (frame, engine, exhaust, knobby tyres, spokes, fork, swingarm, plastics; rider limbs, helmet, goggles, boots) | Procedural geometry in `Bike/MXBike.cpp` via `FX/MXMeshKit` (UProceduralMeshComponent). Colours are vertex colours. |
| Track surface, ramps, mud puddles, cool-strip chevrons, barriers, finish decks, gantries, lane lines | Procedural geometry in `Track/MXTrackActor.cpp`, generated from the same track model as the physics |
| Hay bales, spectators, floodlight poles and light banks | Runtime `UStaticMesh` built with `MXMeshKit::BuildStaticMesh`, drawn instanced (HISM) |
| Dust, mud, grass, steam and smoke particles | `FX/MXFXManager.cpp`: one instanced quad billboarded per view by `M_MX_Particle` |
| Materials (`/Game/HeatlineMX/Materials/M_MX_*`) | Created by `Tools/build_content.py` with Unreal's MaterialEditingLibrary (node graphs only, no textures) |
| Engine, landing, crash, cool-strip, overheat, UI and crowd sounds | Synthesised in real time by `Audio/MXEngineAudio.cpp` (USynthComponent). No sample files. |
| HUD and menu text | Unreal's built-in Roboto via `FCoreStyle::GetDefaultFontStyle` |
| Sky, sun, fog, post-process | Engine components (SkyAtmosphere, DirectionalLight, SkyLight, ExponentialHeightFog, PostProcess) configured in `Race/MXEnvironment.cpp` |
| Data Assets, Blueprints, map | Created by `Tools/build_content.py` from project classes and data |

## Research sources (not shipped)
* **Game layouts** (`Content/Courses/nes_t*.json`, `docs/TRACK_MANIFEST.md`): obstacle order, lanes
  and spacing. These were derived by `Tools/nes_manifest/build_manifest.py` from the public
  [cyneprepou4uk/NES-Games-Disassembly](https://github.com/cyneprepou4uk/NES-Games-Disassembly)
  Excitebike listing. The listing was streamed at build time and **no ROM or disassembly bytes are
  stored** in the project. Positions were checked visually against the nesmaps.com track maps, which
  were viewed in a browser and not saved.
* **Mechanics facts** (`docs/RESEARCH_ORIGINAL.md`): the Nintendo Classic Mini manual (CLV-P-NAAHE),
  the original 1985 US manual (archive.org text), and the MIT-licensed
  [ToolAssisted-run/exciteBot](https://github.com/ToolAssisted-run/exciteBot) physics spec and engine.
  exciteBot was read for facts only; no code was copied.
* **Names:** "Heatline MX" is an original title. The course names are generic ("Course 1–5"), and
  Nintendo's names, logos and graphics are not used. "Excitebike" appears only in documentation, to
  describe the source of the layouts.
